iDigitalStudies Ready-to-Use HTML Landing Page

FILES
- index.html — complete landing page
- style.css — responsive design
- script.js — mobile menu, counters, smooth scroll and WhatsApp lead form
- assets/design-reference.png — generated visual design reference

USE
1. Upload the whole folder to your hosting, or upload its contents into a public folder.
2. Open index.html.
3. Edit phone number, email, copy and claims in index.html.
4. Replace the WhatsApp number in index.html and script.js if needed.
5. Add Google Ads / Meta Pixel IDs in the <head> before running paid traffic.

NOTES
- The page is framework-free: HTML + CSS + JavaScript.
- It uses Google Fonts and iDigitalStudies image URLs, so internet access is needed for those assets.
- Institute-reported statistics are marked for verification before publishing.
